# 👥 HR Analytics Dashboard | Power BI

A comprehensive **HR Analytics Dashboard** built using **Power BI** to analyze workforce trends, employee demographics, attrition, performance, and workforce distribution. This dashboard transforms HR data into interactive visualizations, enabling HR managers and business leaders to make informed decisions about employee retention, workforce planning, and organizational performance.

---

# 📌 Project Overview

The HR Analytics Dashboard provides actionable insights into employee data by tracking workforce composition, attrition trends, department performance, and employee demographics. It helps organizations identify key factors influencing employee retention and optimize human resource strategies.

The dashboard includes analysis of:

- 👨‍💼 Employee Overview
- 📉 Attrition Analysis
- 🏢 Department-wise Employee Distribution
- 👥 Gender Diversity Analysis
- 🎓 Education Analysis
- 💰 Salary Analysis
- 📅 Age & Experience Analysis
- ⭐ Employee Performance
- 📊 HR KPIs

---

# 🚀 Project Objectives

This project aims to answer important HR business questions such as:

- What is the total number of employees?
- What is the employee attrition rate?
- Which departments have the highest attrition?
- What is the gender distribution across the organization?
- Which education backgrounds are most common?
- How are employees distributed across different age groups?
- What is the average monthly salary?
- Which departments have the largest workforce?

# 📊 Project Workflow

### 🔹 1. Data Collection

- Imported HR dataset from Excel.
- Loaded employee records into Power BI.

### 🔹 2. Data Cleaning

- Removed duplicate records.
- Handled missing values.
- Corrected data types.
- Standardized categorical values.

### 🔹 3. Data Transformation

- Applied Power Query transformations.
- Created calculated columns.
- Optimized the data model.

### 🔹 4. Data Modeling

- Built relationships between tables.
- Created DAX measures.
- Developed reusable HR calculations.
